# sopher.ai audit and refresh — October 2026

A full pass over security, correctness, performance and repository health,
done on branch `chore/portfolio-refresh` against `main` at `1454bd0` (PR #161).
The work combined three independent read-only audits (security; AI, workflow,
billing and database; UI, performance and hygiene), `pnpm audit`, the AI
Gateway model catalogue and seven days of production runtime errors. Every
finding below was re-checked against current code before it was fixed.

## Dependencies

- **Next.js 16.2.12 → 16.4.0.** Fixes the critical image-optimizer and
  `next/og` `ImageResponse` remote-code-execution advisories; the app ships
  `opengraph-image.tsx` routes. React 19.3.
- **Workflow SDK 4.8 → 5.1.** Fewer queue round trips and compressed payloads;
  no v5 breaking API is used here (verified against the v5 migration notes).
- `shadcn` (a CLI whose CSS is imported at build time) moved to
  devDependencies, removing an MCP SDK / express / undici tree from production.
  Five packages with zero imports were removed.
- Stale `pnpm.overrides` that themselves pinned vulnerable versions (sharp,
  nanoid, fast-uri, brace-expansion) were replaced with patched floors.
- **Held back deliberately:** `stripe` 23 re-pins the Stripe API version,
  changing payment and webhook payload shapes; `mermaid` 12 re-lays out and
  recolours every existing diagram and drops older Safari. TypeScript 7,
  ESLint 10 and Vitest 5 were out of scope.

## Models

Tiers moved from Sonnet 5 / Opus 5 to **Sonnet 5.5 / Opus 5.5** (Haiku 4.5
remains the cheap tier; there is no newer Haiku). The prose fallback moved from
Sonnet 4.6, which cost more than the primary and therefore set every writer
credit hold, to Sonnet 5.

The 5.5 models cannot disable thinking, which the metering policy assumed.
Verified live through the Gateway: Sonnet 5.5 accepts `thinking:
between_tools`; Opus 5.5 always thinks adaptively and is bounded with `effort:
low`; Haiku 4.5 rejects `effort`; Sonnet 5 rejects `between_tools`.
`anthropicReasoningOptions()` in `src/ai/models.ts` encodes this per model and
picks a setting every model in a fallback chain accepts. Unknown slugs are now
priced at the per-field maximum of the table, so they can never be undercharged.

## Correctness and cost

- **Tool-step chatter saved as chapter prose.** The writer streamed and saved
  text from every tool-loop step ("I'll check the story bible first…"). Only
  the prose step is kept now, and a draft cut off at the token limit fails as
  retryable instead of being saved.
- **The whole manuscript was copied into `generation_runs.config`** and
  rewritten with an optimistic compare several times per chapter, then read
  in full by every progress poll. Persisted chapter text is now pruned to a
  digest; readers accept old and new shapes.
- Outline, scene-plan and publishing schemas no longer send provider-stripped
  constraints that caused paid retries; the continuity prompt no longer offers
  a tool it forbids; continuity reuses its corpus from cache across six
  phases and digests the manuscript in SQL instead of loading it ~19 times.
- Paid outputs are checkpointed before persistence, so a retry never re-buys
  them; `$` patterns in revision text are applied literally.
- New indexes on `credit_ledger(run_id)` and `(user_id, external_ref
  text_pattern_ops)`; `llm_calls.cache_write_tokens` is now recorded
  (migration `0022`).
- Run health was computed (with a Workflow API probe **and** a database write)
  twice per page view, double-counting "missing workflow" evidence. It is now
  deduplicated per request and counted at most once a minute.

## Found by the end-to-end run

A real Draft-tier book was generated locally on the refreshed branch
(collaborative question, outline approval, a credit pause, resume,
continuity, completion). It caught problems no unit test or auditor had:

- **Sonnet 5.5 wrote no chapters.** The working method tells the writer to
  look up every person, place and object before writing; Sonnet 5.5 spent
  both tool-enabled steps on lookups and ended the tool-free final step with
  "let me check…". Six chapters were saved as 10–24 words of working notes.
  The writer now asks for one parallel round of lookups, appends a "tools are
  closed, write the chapter now" turn when the final step arrives with no
  chapter, and refuses (retryably) any draft under a quarter of its target.
  A regenerated chapter came back at 1,059 words. When the nudge path fires,
  that chapter's canon writes (`entityUpsert`) do not run.
- **Sonnet 5.5 needs more output room.** Thinking cannot be disabled and its
  prose steps measured ~1.9 output tokens per saved word, so a chapter at
  the old 2× cap ran into it; one chapter failed all four retries as
  truncated and failed the book. The cap is now 3 tokens per target word
  (per-wave holds remain below `main`'s), and the failed book resumed from
  its three saved chapters.
- **Streamed model ids were billed at the unknown-model rate since
  2026-07-31.** Streamed Gateway responses report the provider's id
  (`claude-sonnet-5`) rather than the slug requested
  (`anthropic/claude-sonnet-5`), which missed the pricing table. On `main`
  every Sonnet chapter draft was billed at Opus 5 rates (about 2.5×). On the
  development database this over-debited three accounts by a combined ~3.96
  credits across 72 calls. Ids are now canonicalized before pricing and
  storage, and falling through to fallback pricing logs a warning.
- After a credit pause resumed, the studio's next step reverted to "Review
  the outline" until a reload (the live-progress merge kept the snapshot's
  `awaiting_input` status); and the pause copy printed raw ledger precision
  ("needs 12.5904 credits").
- The finished-manuscript gate accepted six 10-word chapters as a complete
  book. With the writer guard this can no longer happen through the writer,
  but a minimum-length check at finalize would be a sensible second line.
- **Quotes ran about a third of real cost.** The drafting estimate assumed
  9.5k input tokens per chapter; the three-step writer loop measures ~38k
  (mostly prompt-cache writes), 5.5 output runs ~2.2 tokens per word, and the
  story-bible pass was not estimated at all. Recalibrated from the run's
  `llm_calls`: a 6 × 1,000-word Draft book now quotes 2.4 credits against ~2.5
  measured. Cache writes dominate writer cost; whether the Gateway's
  `caching: "auto"` should mark every tool step is worth measuring.
- The wizard says a quote is "covered by your balance" when the run's peak
  per-wave credit hold (12.6 credits for a 1.2-credit Draft book) is higher;
  the run then pauses for credits. Documented behaviour, but misleading for
  small balances.

## Production errors

- `/studio` threw `UnauthorizedError` (8 hits) and `/opengraph-image%5C`
  returned 500. Both groups share timestamps: a scanner sending
  backslash-mangled paths. The proxy now returns 404 for `\` / `%5C` paths, and
  signed-out page renders redirect to sign-in instead of throwing.

## UI and repository

- Hydration mismatch in the live run viewer's clock; focus ring missing on the
  brief editor (WCAG 2.4.7); raw colours on marketing pages replaced with
  semantic tokens (contrast asserted in tests); error boundaries for marketing,
  admin, reader and root; seven dead components removed.
- Independent server queries on the editor, manuscript and write pages now run
  in parallel; archived-draft recovery is computed in Postgres.
- CI: every job has a timeout, the merged rebuild branch trigger is gone, and
  the audit gate passes again. A test file that TypeScript silently never
  checked (shadowed by a same-named `.ts`) is now typechecked.
- The repository had been living in an iCloud-synced folder: evicted
  `node_modules` files hung `tsc`, and `foo 2.ts` conflict copies appeared.
  Those copies are now excluded from tsconfig and ESLint, and CI rejects them.

## Deferred, with reasons

- **Mid-stream provider drop is still fatal to a run** (W11). The path fails
  closed on purpose; no existing helper can prove an in-flight call was not
  billed, and an author must never be charged for an ambiguous call.
- **Refunds do not revoke the full-book unlock.** Purchase rows record credits
  granted (with bonus) while refunds record dollars, so netting is not sound
  on the current ledger, and it is a product decision.
- `noUncheckedIndexedAccess` (452 errors) and Next's `partialPrefetching`
  (studio routes read auth data outside `<Suspense>`) are worth adopting in a
  dedicated pass.
- The premium-tier public price (36 cr) is kept as an upper bound until it is
  re-measured from real Opus 5.5 runs.
